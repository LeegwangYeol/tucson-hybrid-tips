# Tucson Hybrid Tips & Secrets 🚙⚡

> **라이브 웹사이트:** [https://tucson-hybrid-tips.vercel.app/](https://tucson-hybrid-tips.vercel.app/)

현대 투싼 하이브리드(NX4/NX4 PE) 오너들을 위한 **스마트키 오작동 예방 팁, 초간단 눈높이 설명서, 숨은 꿀팁 및 시크릿 기능**을 총망라한 인터랙티브 가이드 웹사이트입니다.

## 🚀 주요 기능 (Features)
- **트렁크 충돌 시뮬레이터:** 스마트키 눌림으로 인한 트렁크 열림 반경 및 충돌 여부 시각화
- **예방 체크리스트:** 7단계 방지 체크리스트 및 상태 저장(브라우저 SafeStorage 적용)
- **초간단 눈높이 매뉴얼:** 딱딱한 공식 매뉴얼을 15개의 이해하기 쉬운 카드로 재구성 (하이브리드 주행, 경고등, 필수 소모품)
- **고급 팁 & 시크릿:** 보배드림 등 커뮤니티에서 발굴한 숨은 클러스터 메뉴, 관성 주행 비법, 필수 악세사리 추천
- **엔터프라이즈급 안정성:** DOM 누수 제로, 무결점 테스트(196/196 E2E Pass), WCAG AAA 접근성 충족

## 🛠 배포 (Deployment)
본 프로젝트는 정적 웹사이트(Static HTML/CSS/JS)로 구성되어 있으며 **Vercel** 환경에 최적화되어 있습니다.
에이전트 스웜(Teamwork Preview)에 의해 구축되었으며, 100% 무결점을 위한 다중 검증 및 독립 감사(Victory Audit)를 통과한 방탄(Bulletproof) 코드입니다.
